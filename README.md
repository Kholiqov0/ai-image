# 🖼️ ai-image

> Управление изображениями через команды на естественном языке  
> Natural language image processing using **Qwen2.5** + **OpenCV**

---

## 📌 Описание

Программа позволяет обрабатывать изображения с помощью текстовых команд на **русском или английском** языке.  
Вместо кнопок — просто пишешь: _«поверни на 90 градусов»_ или _«сделай чёрно-белым»_.

**Как это работает:**

```
Команда пользователя
       ↓
Qwen2.5-3B-Instruct (LM Studio)   ← понимает команду, возвращает JSON
       ↓
{"action": "rotate", "angle": 90}
       ↓
OpenCV                             ← выполняет операцию над изображением
       ↓
Результат сохраняется в папку output/
```

## 🤖 Используемая модель

| Параметр | Значение |
|----------|----------|
| Модель | **Qwen2.5-3B-Instruct** |
| Разработчик | Alibaba Cloud |
| Размер | 3 миллиарда параметров |
| Тип | Instruct (обучена следовать инструкциям) |
| Запуск | Локально через LM Studio (без интернета) |

**Почему Qwen2.5-3B-Instruct:**
- 🏠 Работает **полностью локально** — не нужен платный API
- 🇷🇺 Хорошо понимает **русский язык**
- ⚡ 3B параметров — оптимальный размер для задачи (быстро, не требует мощного GPU)
- 🎯 Суффикс **Instruct** — модель обучена точно выполнять инструкции и возвращать структурированный JSON

## ⚙️ Поддерживаемые команды (8 операций)

| # | Команда | Пример |
|---|---------|--------|
| 1 | Поворот | `поверни на 90 градусов` |
| 2 | Изменение размера | `уменьши в 2 раза` / `сделай 800x600` |
| 3 | Цветовой канал | `выдели красный канал` |
| 4 | Размытие | `сделай размытие` |
| 5 | Отражение | `отрази по горизонтали` |
| 6 | Чёрно-белый | `сделай чёрно-белым` |
| 7 | Яркость | `увеличь яркость на 80` |
| 8 | Детекция краёв | `выдели края` |

## 🛠️ Установка и запуск

### 1. Требования

- Python 3.8+
- [LM Studio](https://lmstudio.ai/) с загруженной моделью `qwen2.5-3b-instruct`

### 2. Установить зависимости

```bash
pip install opencv-python pillow numpy requests
```

### 3. Запустить LM Studio

1. Открыть LM Studio
2. Загрузить модель **qwen2.5-3b-instruct**
3. Перейти во вкладку **Local Server**
4. Нажать **Start Server** (порт `1234`)

### 4. Запустить программу

```bash
python main.py
```
